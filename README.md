## 🌸 About This Repository

Bloom Library merupakan perpustakaan digital sederhana
yang menyediakan berbagai koleksi ebook dalam format PDF
serta informasi bibliografi setiap buku.

Repository ini dibuat untuk memudahkan pengguna
dalam mengakses dan membaca koleksi buku secara digital.

## 🌿 Repository Contents

| Folder / File | Keterangan |
|---|---|
| 📚 `ebook/` | Berisi 10 koleksi ebook dalam format PDF dan ringkasan UGC. |
| 🌱 `metadata/` | Berisi informasi bibliografi dari koleksi buku. |
| 🌷 `index.html` | Halaman utama website Bloom Library. |

## 📖 Book Collection

Tersedia 10 judul buku yang dapat diakses dan dibaca
melalui halaman utama Digital Library.

## 🌼 UGC Collection

Koleksi nomor 11 berisi ringkasan pemaparan
User Generated Content (UGC) beserta wawasan baru
yang diperoleh dari kegiatan tersebut.
